Match Centre Admin

Settings save to this browser only (there's no shared server) — so open this page on the TV's own browser to configure it directly, or use the same browser you use for the display.

Live Scores (Play-Cricket)

Set the scorecard proxy URL below (see setup instructions), then add a Play-Cricket Match ID to any of the 4 slots to pull live scores automatically every 5 seconds. Leave a Match ID blank to use that slot's manual fields instead.

Featured Match

Pick which of the 4 fixture slots below gets the big featured panel (video + large score). If that match is being live streamed, turn the toggle on and add the stream URL — the stream itself (e.g. via Frogbox) already overlays the score, so the Match Centre will show only the video and hide its own score/batting overlay. Turn it off to show the manual scorecard details instead.

Club News

Club Sponsors

Shown one at a time, slideshow-style — upload one or more images and set how many seconds each one displays before moving to the next. Leave empty to hide the sponsor panel entirely (club news will take the full width instead). Uploaded images are stored directly in this browser, so keep them reasonably small (a few hundred KB each).
